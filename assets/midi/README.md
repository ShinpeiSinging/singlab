# Preset MIDI files

Put the bundled preset songs here before publishing:

- `jiyu-ni-naritai-chorus.mid`
- `yarukoto-takusan.mid`
- `shiawase-wo-tsukamu-tame.mid`
- `jiyu-wa-ikaga.mid`
- `yamerarenai.mid`
- `maho-no-ringo.mid`
- `kaeritai.mid`
- `taisetsu-na-tomodachi-e.mid`
- `glass-no-kutsu.mid`

These files are loaded directly by the browser from GitHub Pages.

Put source files in `preset-midi-drop/`, then run this from the repository root:

```powershell
.\scripts\copy_preset_midi.ps1
```
