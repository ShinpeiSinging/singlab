# Preset MIDI files

Put the bundled preset songs here before publishing:

- `shiawase-wo-tsukamu-tame.mid`
- `jiyu-ni-naritai-chorus.mid`
- `yamerarenai.mid`
- `maho-no-ringo.mid`
- `kaeritai.mid`
- `glass-no-kutsu.mid`

These files are loaded directly by the browser from GitHub Pages.

Run this from the repository root on the Windows PC that can access `G:`:

```powershell
.\scripts\copy_preset_midi.ps1
```
